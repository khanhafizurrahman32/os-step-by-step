# Part IV · Distribution

**The question:** how do you build a system that works when parts of it fail and messages get lost?

One lesson covers the three chapters: reliable messaging and RPC, NFS (stateless + idempotent) and AFS (callbacks + whole-file caching) — **[L27](l27-dfs.md)**.

If you're preparing for system-design interviews, this is the bridge to distributed systems books like *Designing Data-Intensive Applications*.
